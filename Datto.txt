The ticket references Citrix VDI servers, and I initially assumed the WZ-CTXND servers may be the relevant VDI servers based on the server naming and environment.
I checked the WZ-CTXND servers for KB5122876, which is the September 2026 Windows Server 2019 update mentioned in the Citrix advisory. KB5122876 was not found in the installed updates on the CTXND servers.
The CTXND servers currently show their last installed Windows patches as 27 March 2026.
Most importantly, I found that Windows Update is disabled on all of the CTXND servers. These servers are also not being patched through Datto RMM patch policies. This appears to have been the existing server configuration since the environment was onboarded; there is no indication that Windows Update was recently disabled as part of this incident.
The CTXND servers appear to be part of an MCS non-persistent Citrix VDI environment. Registry information on WZ-CTXND001 shows:
Machine Catalog: WZ-MCS-Server2019-ND-NEW
PersistUserChanges: Discard
D: drive labelled MCSWCDisk
Because the machines are non-persistent, changes made directly to an individual VDI may not persist when the machine is refreshed/recreated. Windows updates for this type of environment would normally need to be applied to the MCS master/golden image, followed by updating/deploying the image to the VDI machines.
During the investigation, there was initially some uncertainty whether the environment was using MCS or PVS, as PvsVmAgent was present on both the suspected base image and CTXND servers. Further investigation of the CTXND servers showed clear MCS indicators, including MachineIdentityServiceAgent, MCSWCDisk, and the WZ-MCS-Server2019-ND-NEW Machine Catalog.
I was unable to access/find the Citrix management console, so I could not verify the Machine Catalog configuration or confirm the exact master/golden image currently being used.
I checked the VMware vCenter environment and identified several servers that could potentially be base/master images. I also noticed a recently added server in Datto RMM named WZ-BASE-2019-ND, which appeared to be a possible master image based on its naming and Citrix-related configuration.
I checked WZ-BASE-2019-ND for KB5122876, but the update was not installed there either.
Further investigation confirmed that WZ-BASE-2019-ND has Citrix VDA and PvsVmAgent components installed. However, based on the registry information available, I could not conclusively confirm that WZ-BASE-2019-ND is the active MCS master/golden image. The MCS VdaStateMirror information found on WZ-CTXND001 was not present on WZ-BASE-2019-ND.
Therefore, before installing the Microsoft OOB update KB5129238, the actual MCS master/golden image and current provisioning configuration should be confirmed.
As this is a Citrix VDI environment and the provisioning configuration could not be fully verified, I recommend confirming with the internal team and the client how the VDI environment was provisioned, which VM/snapshot is currently being used as the MCS master image, and how image updates are normally deployed.
STS team has been informed of the findings for further investigation and confirmation before making any changes to the Citrix VDI environment.
